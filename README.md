# AMTF — Agent Memory Transfer Format

Agent memory should be portable, not hostage to the platform that happened to store it. AMTF is a thin, explicit export format plus the machinery to argue about memory quality reproducibly: a write gate, a provenance chain, a forgetting metric, and a conformance suite. Everything here is standard-library Python, runs offline, and prints its own evidence.

**Status**: public draft v1.0 · 44 files · 13 tools (1,596 lines) + spec, SDK, 3 adapters (549 lines) + conformance suite

## The gap

Memory poisoning moved fast: MINJA reports a 98.2% injection success rate, and MPBench (ICML 2026, Huawei + University of Waterloo) states plainly that current memory systems have no provenance-tracking mechanism.

The attack side is well benchmarked. The admission side is not: a third party cannot re-run a vendor's claim about what its memory system lets through. This repository ships the reproducible half — gates with pass/fail vectors, a tamper-evident chain, a portable schema, and conformance tests anyone can execute.

## Quickstart (stdlib only, Python 3.10+)

```bash
python tools/poison_admission_gate.py selftest      # admission gate, L1/L2 layers
python conformance/conformance_suite.py             # expect: 10/10 ALL GREEN
python sdk/python/amtf/cli.py validate examples/amtf_out.json
python adapters/mem0_to_amtf.py examples/sample_mem0_export.json
```

## Honest limits

- **L3 latent poison is not in this repository.** The public build covers L1/L2 and reports `l3_enabled: false` in every verdict; on the 14-sample calibration corpus it flags 5 of 8 poison samples and says so. The latent-trigger layer and its calibration table ship only in the partner build.
- **The admission gate fails safe, not open.** Without the L3 layer, inputs matching a coarse conditional-trigger shape return `REVIEW` (human escalation) instead of `ADMIT`.
- **`guard_gate`'s I2 contract test needs the host engine**, which is not bundled. The selftest prints `I2 SKIP` rather than reporting a pass it did not earn.
- **Certification here is a procedure, not a service.** This repository publishes the criteria (`docs/AUDIT-CRITERIA.md`); it does not run a registry, an audit SLA, or a hosted endpoint. Turning a passing run into a signed certificate is a separate, contracted act.
- The gate is a reference implementation: the adversarial corpus it was tuned on is 14 samples, not thousands.

**Checklist open, signature closed.** `docs/AUDIT-CRITERIA.md` lists the nine criteria a certification run executes, each with a command you can run yourself today — and the certificate fields, in the clear. What stays private is the part that makes a certificate worth anything: the thresholds, who signs, and what voids a signature. A checklist nobody can read is a toll booth; a signature anybody can reproduce is a printout.

**Behind the lock.** The public gate tells you *that* a rule fired and at what weight; it does not tell you how the weights were calibrated, nor how latent triggers are patterned — those come from 14 adjudicated real-world samples and the labelling rules behind them. `conformance/` proves a memory bundle is well-formed; it does not certify that the system that produced it is trustworthy. Adapters cover Mem0, Zep, and generic JSONL; if your runtime is not one of the three, the missing piece is a mapping you can pay someone to write — we publish the interface, not your integration.

**How to ask.** Send two things: (1) what you are building and what memory actually does in it; (2) which layer above you want and what you already tried. One-line messages get one-line replies — not rudeness, just arithmetic.

**Not a fit**: you want a hosted service, or a certificate without letting anyone run tests against your system. **A fit**: you run a memory backend and want interop, or you need admission control you can show an auditor.
